# FinansPanel - Borc & Odeme Yonetim Sistemi

Kisisel ve kurumsal finansal yonetim icin kapsamli borc ve odeme takip sistemi.

## Ozellikler

- Borc ve alacak takibi
- Odeme planlama ve takvim gorunumu
- Firma bazli finansal yonetim
- Gelir-gider raporlari ve grafikler
- Excel aktarim/icerik alma
- Karanlik/aydinlik tema destegi
- Mobil uyumlu tasarim

## Canli Erisim

Site GitHub Pages uzerinden yayinlanmaktadir:
`https://mustafaguven001.github.io/finans/`

## Teknolojiler

- React 18 (UMD)
- Vanilla CSS (ozel tasarim sistemi)
- SheetJS (Excel islemleri)
- localStorage (veri saklama)
